# CodeLess 受控试用用户手册

修订日期：2026-11-04（Asia/Tokyo）。适用于受控试用版，界面基线为 `aefaca193af3019bcadbcf8fdf3f6424baee750c`。当前发布限制见[前端交付说明](delivery/frontend.md)。

## 可以制作什么

适合个人展示页、活动展示页、任务管理和搜索分类页。仅生成受控 Vue 前端应用，数据使用静态内容、Mock 或 LocalStorage。活动报名只能演示交互，不会建立真实报名后台；LocalStorage 数据仅保存在当前浏览器，清理站点数据会丢失，也不会自动跨设备同步。

不支持 React、独立 HTML 策略、生成后端或数据库、支付、任意依赖安装及任意命令。使用完整边界见[范围冻结](scope.md)。请勿在需求或演示数据中输入密钥、密码或个人敏感信息。

## 登录和新建应用

1. 使用维护者提供的受控试用账号登录。普通用户只能访问自己的应用；管理入口需管理员权限。
2. 在“我的应用”点击“新建应用”，填写“应用名称”、可选“简介”，在“数据模式”选择“静态数据”“Mock 数据”或“LocalStorage”，点击“创建”。
3. 进入工作台后输入需求。例如：“创建个人作品展示页，包含姓名、简介和三张作品卡片，使用静态数据；不访问外部接口。”点击“开始生成”。需求最多 8000 个字符。

## 查看计划、生成和修复

观察任务需求、任务状态及事件日志。任务通常按 PLAN（计划）、GENERATE（生成）、VERIFY（验证）推进；验证失败可能进入 REPAIR（修复）。修复自动受预算和截止时间约束，不保证每次都成功。READY 表示此任务形成了已验证版本，FAILED 表示任务失败；日志里的模型文字不是成功凭据。

等待时可使用“刷新任务”或保存“任务恢复链接”。连接中断时先恢复同一任务并确认最终状态，避免重复提交。可用“取消任务”请求取消，等待终态；请求已发送不代表已完成取消。生成失败时已有可用版本继续保留；第一次生成失败则暂无预览。

## 预览、版本和组件修改

1. 在“版本记录”中检查版本编号、ID、摘要与“已通过验证”状态。点击“查看源码并预览”；草稿或验证失败版本仅能“查看源码”。“当前预览”和“当前可用”可能不同。
2. “桌面”“手机”切换预览宽度；它不能替代真实设备验收。页面过期或加载失败时点击“刷新预览”。
3. 勾选“选择组件进行修改”，在预览中选择可修改组件，核对组件与基版本。也可展开“使用键盘选择源码组件”。
4. 填写“组件修改描述”，例如“将作品卡片正文颜色改为 #1d4ed8”。勾选“我确认修改影响整个源码组件及所有共享实例”，点击“创建组件修改”。这是源码组件级修改，共享实例、其他页面可能一起变化。
5. 等待修改任务完成；必要时“刷新修改状态”。成功后核对新版本和预览，重新选择组件；失败时旧版本仍可用。版本冲突时刷新版本后重新选择，不能沿用过期选择强制覆盖。

## 发布、封面和下载

1. 点击“发布”打开面板，核对“待发布版本”的编号、ID、源码摘要和构建产物摘要。切换预览历史版本不会自动把它设为待发布目标，以面板显示为准。
2. 勾选“我确认公开发布上方版本”，点击“确认发布”。必须登录且目标已验证。等待“发布成功”；“已受理，正在部署与检查”尚不是成功。用“刷新发布状态”读取结果。
3. 复制成功发布记录的公开地址，用新的浏览器上下文访问并刷新。分享地址对应成功发布版本，可能与当前选定的下载版本不同。
4. 封面独立处理：用“刷新封面”查看状态。“封面已生成”及实际图片才表示成功；占位图、排队、失败都不能当作已生成封面。封面不可用时网站仍可能已经发布。“查看封面对应页面”指向封面绑定入口。
5. 点击“下载源码 · v…”；先核对“下载版本”和“源码摘要”。按钮提示已开始下载后，还要确认浏览器保存了 ZIP。需要交接时记录文件 SHA256，并核对包内 `codeless-export.json` 的版本和摘要。下载不是发布动作，草稿/失败版本不可下载。

## 常见失败及下一步

| 现象 | 操作 |
| --- | --- |
| 登录过期 / 401 | 重新登录，再恢复原任务；不要公开 Cookie 或认证 trace。 |
| 应用不存在或无权访问 / 404 | 核对账号与应用地址，请维护者确认归属，不尝试绕过权限。 |
| 事件断开、结果未知 | 等待连接恢复，点击“刷新任务”，保留任务 ID；未知不算成功。 |
| 生成/修复失败 | 保留错误码、任务 ID、失败版本；查看最近可用版本，缩小需求后再创建新任务。 |
| 版本冲突 / 409 | 点击“刷新版本”，重新核对基版本并选择组件。 |
| 预览过期或空白 | 点击“刷新预览”；持续失败时保留版本 ID 和报错交给维护者。 |
| 公开站点尚未配置 | 联系维护者准备托管配置，用户无法通过反复点击解决。 |
| 发布结果未知 | 点击“重新读取版本与发布记录”，确认原请求状态后再行动，避免重复发布。 |
| 发布失败 | 保留发布 ID 与错误；旧成功地址继续保留。确认原因后才创建新发布记录。 |
| 封面暂不可用 | “刷新封面”；保留发布 ID，不能用占位图作成功证据。 |
| 下载失败 / 摘要不匹配 | 重新读取版本后再下载；不要分发未校验包，记录版本与错误交给维护者。 |

反馈需包含发生时间及时区、应用/任务/版本/发布 ID、操作步骤、预期和实际结果及脱敏截图；不发送密码、Cookie、token、私钥或完整认证日志。维护者说明见[环境准备](environment.md)，演示操作见[完整演示脚本](demo/full-script.md)。
