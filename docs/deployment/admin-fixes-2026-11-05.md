# 后台修复与部署：2026-11-05

基于 main e200cb5；保留已合并的入口与预览修复。

## 数据口径与历史整理

后台所有列表和指标默认排除明确标记的测试账号、测试应用、测试发布；模型用量另排除 mock/fixture 模型。includeTest=true 可核对全部原始记录，模拟调用绝不会被伪装成真实零消耗。真实调用没有返回 tokens 时继续显示未知。

V7 增加来源标记、取消人、发布失败原因、会话版本与账号管理审计表。历史整理工具 infra/public/mark-legacy-test-data.py 默认只读；部署备份后显式 --apply，只标记固定 ID 且名称符合既有验收身份的项目。五条失败保留原状态，从原私有阶段账本回填原因。旧 demo 验证博客归档，真实调用及财务预留全部保留。

公网验收使用 infra/public/acceptance_accounts.py 创建专用测试账号与隔离的失败版本夹具，不再使用 demo 创建内容，也不再把历史 demo 的版本当作隔离夹具。无论成功还是异常退出，清理入口取消测试任务、下线测试网站、归档项目并停用测试账号。历史记录保留测试标记，便于审计；清理失败明确报错，不能报告成功。

## 任务与用户管理

取消仍使用 CANCELLED 终态码，新增 cancelledBy=USER/ADMIN/UNKNOWN。旧数据依据准确事件消息回填；未知来源使用中性文案。取消在工作台与预览区显示已取消，已有可用版本保留。

后台显示应用名称、邮箱、版本号与发布失败原因；完整编号收进详情，状态中文显示，所有时间与趋势日界限采用 Asia/Shanghai。用户可按邮箱/名称搜索，选择所有者筛选。

管理员可创建普通用户或管理员、设置测试标记、启停账号和重置密码。密码至少12字符且不超过72个UTF-8字节，BCrypt存储。密码和完整请求体不进审计。停用或重置密码递增会话版本，每次鉴权及SSE会话检查都校验该版本；不能停用自己或最后一个可用管理员。

## 版本身份

Vite自动输出 /version.json（完整提交、构建时间、dirty）。nginx让此文件重新验证缓存；后台显示版本与北京时间构建时间。API包内build-info记录构建时传入的codeless.build.commit与实际构建时间，/api/health返回同一身份。正式API发布构建器自动传入冻结提交；导出的前端源码通过CODELESS_BUILD_COMMIT传入。发布只能使用已提交且clean的源码。

## 交付边界

本次只进行构建、类型/语法和部署启动及只读身份检查，不自动执行付费生成或人工功能验收。部署前备份数据库、API、前端、入口配置与替换的运行源码；保留现有模型配置和累计预算账本。人工验收由用户进行。
