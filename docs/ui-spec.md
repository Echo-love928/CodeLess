# CodeLess 前端 UI 约定

## 当前定位

当前是独立前端演示。登录页提供本地入口，应用列表展示一份静态示例，工作台提供页面预览、设备切换、标题及按钮文案调整、状态组件演示。更改仅保留在本次页面会话内；无鉴权、持久化、生成或发布能力。发布按钮保持禁用。

## 页面与导航

| 路由 | 页面 | 当前可操作内容 |
| --- | --- | --- |
| `/login` | 登录入口 | 进入本地演示 |
| `/apps` | 应用列表 | 搜索示例应用、打开工作台、填写需求和选择起步场景 |
| `/workbench/:id` | 工作台 | 返回应用列表、桌面/手机预览、文案即时调整、状态组件演示 |

未知路径重定向到 `/apps`。Vite 开发和预览服务支持 history 路由刷新；正式部署需配置相同的 SPA 回退到 `index.html`。

## 视觉与组件

画布 `#f5f6f8`、面板 `#ffffff`、正文 `#222936`、操作蓝 `#4263eb`、边线 `#e3e6ec`。系统中文无衬线字体为主体，品牌使用 Trebuchet MS。示例作品的浅绿色属于作品自身，不与平台按钮色混用。品牌图标 `BrandLogo` 与 favicon 采用同一“打开的 C”构形；`ClubPage` 在应用列表、登录页和工作台复用，避免三处内容偏离。`UiIcon` 提供界面内的简单线性图标。

工作台的主要空间留给页面预览。桌面布局为页面导航、预览画布和属性面板三栏；窄屏隐藏页面导航，但保留可访问的属性面板。`StatePanel` 继续处理加载、空态和错误态；错误态为 `role=alert`，加载态设置 `aria-busy`。所有交互保留可见键盘焦点；用户选择减少动态效果时停用动画。

## 交互边界

- “新建应用”聚焦需求输入；场景卡片填入示例需求。提交后明确提示生成服务尚未接入。
- 搜索只过滤本地示例；无结果时提供清除搜索操作。
- 工作台选中标题或按钮后可调整文案。切换状态会清除选中态，刷新后恢复示例文案。
- 桌面/手机开关改变预览画布宽度；状态选择器仅供展示和验收。
- 登录字段保持禁用，演示入口直接进入应用列表；发布保持禁用。

## 本地检查

在 `apps/web` 内运行 `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build`。浏览器验收运行 `pnpm smoke`；如使用本机 Chrome 通道，在执行前设置 `CODELESS_PLAYWRIGHT_CHANNEL=chrome`。浏览器用例覆盖三页刷新、搜索、需求反馈、文案编辑、设备切换、状态组件与窄屏布局。

独立设计方案和原型位于 `docs/ui-preview/`；以 Vue 页面为当前实施结果。
