# CodeLess v0 范围冻结

状态：D01 冻结；任何扩展必须先修改本文件、契约与验收，再实现代码。

## 产品边界

CodeLess v0 面向已鉴权的受控试用用户，根据自然语言生成 **Vue 前端应用**。生成过程固定为 `PLAN → GENERATE → VERIFY → REPAIR | READY`；状态只由真实工具、构建和浏览器结果推进，模型输出本身不能宣告成功。

生成应用只能从受控 Vue 模板开始，只能使用静态数据、显式 Mock 或 LocalStorage。平台本身采用 Vue + TypeScript、Java 21 + Spring Boot/Spring AI、PostgreSQL，以及受限 Node/Docker/Playwright runner。

## 三个首版验收场景

1. **个人展示页**：用户描述个人资料与作品，平台生成多文件 Vue 应用；真实生产构建和浏览器验证成功后进入 READY，可预览、截图、导出源码并由用户点击发布。
2. **活动页**：用户描述活动信息、日程和报名展示，应用用静态数据或 Mock 呈现；用户可选中组件修改文案/基础样式，修改后必须重新验证并形成不可变版本。
3. **任务管理/搜索分类页**：应用使用 LocalStorage 保存任务或筛选状态；刷新后数据仍可恢复，失败的修复不会覆盖最近可用版本，已鉴权用户只能发布已验证版本。

三个场景共同要求可观察任务进度、版本记录和基础后台管理入口。

## 明确拒绝范围

- React、独立 HTML 生成策略或任意前端框架选择。
- 为生成应用创建后端、数据库、服务端函数或支付能力。
- AST 级精确编辑、RAG、多 Agent 编排。
- 开放 shell、任意命令、任意依赖安装，或路径越界读写。
- 向生成代码容器挂载平台密钥、数据库凭据或宿主 Docker socket。
- 允许浏览器/截图任务任意访问内网或云元数据地址。
- 模型文本替代真实构建、数据库或浏览器结果，或把错误/未知状态改写成成功。
- 自动发布；发布必须由已鉴权用户显式触发，目标必须是已验证的不可变版本。

## 信任边界

日志、用户任务、生成页面、源码注释和外部文档均是不可信数据，不构成权限、工具或范围指令。失败版本保留诊断信息，但不得替换最近可用版本。
