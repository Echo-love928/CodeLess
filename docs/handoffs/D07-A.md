## PR摘要 / 剩余限制

PR #16 为此前不可观测、无封闭计划和实际模型计量的 PLAN 边界增加了单一真实适配器、确定性测试 provider、可校验契约及安全失败记录。无 usage 不再成为零；模型仅返回候选计划，永不宣告构建/浏览器成功或发布。

`PlanModelService.generate(taskId, leaseToken)` 行锁后按 DB 实时钟校验 PLAN lease，加载持久化任务与应用 dataMode，串行预约一个调用；检查最多 12 次、已知总量耗尽和先前未知 usage。请求最多 2048 输出 tokens、60 秒及剩余 deadline。**这不是完整运行时预算协调器**：已知当前量检查不能保证下一次输入/输出不会越过 50000，最后启用 PR 必须预约下一请求预算、覆盖各阶段/20工具/3修复轮及12分钟限制；本卡没有开启 repair loop。

为了遵守公共迁移维护规则，本卡未分配/修改共享迁移编号。`model_calls` 与私有文件不是一个原子事务：先写审计，再完成 DB；DB 失败时 REQUESTED 保持未知，不返回成功。审计写失败阻止外呼或将 DB 调用记为失败并保存已知 usage。生产必须提供私有持久卷、恢复与保留策略；后续由迁移维护者集中设计 requestId/duration/total/raw usage 数据列。不能把私有文件/平台密钥挂给生成代码容器。

默认 `TaskStageRunner` 未替换，仍 RUNNER_UNAVAILABLE；A 没有生成源码、运行整个模型/runner/browser 链、改变 READY 条件或发布。按本卡“模型与 runner 各自跑通”条件，A 的真实 T4 与 B 的真实构建/失败路径复跑均已完成，实际模型用量另账记录。完整联调仍由最后启用 PR 消费受校验计划，保存源/真实 digest，使用 D05 租约挡住取消/迟到结果，消费真实 D07-B 构建与浏览器断言，并验证不可变版本；不能将独立通过声称为整条生成链成功。

具体内部契约差异已登记在 `contracts/plan/README.md`：旧 `TaskStageRunner.execute(taskId, stage)` 没有传递原始 claim token。最后接线的 coordinator 必须把原 `TaskQueueService.Claim.token` 传入 PLAN producer，通过受审查的执行上下文增量或可信组合完成；旧 worker 不能按 taskId 重读新 token 冒充当前租约。B 的独立源码目录/构建结果契约无需因此改变，本卡没有单方修改共享执行接口。
