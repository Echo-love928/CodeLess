## 实现与契约

| 子项 | 实现 |
| --- | --- |
| D03-A-01 | `services/api/src/main/java/dev/codeless/api/auth/` 中的账号初始化、登录、退出和 BCrypt 校验；Flyway `V2__authentication.sql` 独立存密码哈希与角色。两组密码由环境变量显式提供且必须不同。 |
| D03-A-02 | `AuthFilter` 对 `/api/v0/` 写请求校验 session 内 CSRF token；`GET /auth/csrf` 发 token；会话 Cookie 为 HttpOnly、host-only、Secure 默认开启、SameSite=Lax，30 分钟超时；登录后轮换 session ID。 |
| D03-A-03 | `OwnershipGuard` 检查应用、任务和版本的所属应用，以及管理员角色；他人资源与不存在资源统一 404。D04 的真实 CRUD handler 尚未建立。 |
| D03-A-04 | `LoginAttempts` 按归一化 email 对 15 分钟内 5 次失败限流；401/403/404/429 使用统一 `ApiError`，异常和响应不带密码。当前限流状态在单进程内存中，多实例部署需共享限流器。 |

认证接口见 `contracts/auth/README.md` 与 `docs/auth.md`。公共 `contracts/openapi.v0.json` 仍声明 Bearer/JWT，和 Cookie 会话方案冲突；本任务未跨维护者边界修改该公共契约。D03-B / 公共契约维护者应在启用真实前端登录前解决差异。应用列表数据仍是前端 mock，真实应用 CRUD 留待 D04。
