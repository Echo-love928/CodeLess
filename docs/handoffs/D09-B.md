allow-same-origin 是生成应用 LocalStorage 的必要能力；与平台/其他版本隔离依靠独立版本 origin。
注册 API 是可信 coordinator 边界，verification 必须来自真实 D08 worker；不能把模型 JSON 接入它。
已完成版本不可覆盖，live handle 关闭后不可恢复；1000条映射上限、显式 revoke/close，留存回收由最后启用 PR 接线。
浏览器必须支持 Secure HttpOnly SameSite=None Partitioned cookie；阻止/不支持时显示不可用。
签发凭据是短期 bearer capability；注销平台会话后的剩余120秒需 coordinator revoke 才能提前撤销，未假称即时撤销。
