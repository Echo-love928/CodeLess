## PR 操作建议

1. 功能分支只包含 `apps/web`、`tests/e2e/bootstrap`、`docs/ui-spec.md`、`docs/ui-preview` 和本交接文档；本地 IDE 目录 `.idea/` 不进入提交。
2. 以 `main` 为 base 创建 D01-B Draft PR，描述当前前端能力、验收结果、演示边界和对 D01-A 的依赖。
3. D01-A 合并后，同步 `main`，核对 `contracts v0` 和前端数据模型，运行根阶段门禁与双端联调，再将 D01-B PR 标为 Ready for review。
