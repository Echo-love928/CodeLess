## 集成后的本地验收

执行日期：2026-09-27。使用 Node 24.16.0、pnpm 12.6.0、本机 Java 21.0.8 和 Chrome；Corepack shim 放在临时目录，Java 仅通过测试进程的 `JAVA_HOME` 选择，未修改系统配置。

| 根目录命令 / 阶段 | 结果 |
| --- | --- |
| `pnpm install --frozen-lockfile` | 退出 0；识别根项目和 `apps/web` 两个 workspace 项目，无需更新锁文件 |
| `pnpm verify:static` | 退出 0；版本声明一致，六类契约正反样例与 OpenAPI 校验通过；前端 lint、Vitest 3/3、类型检查和 Vite 构建通过 |
| `verify:api`（由 `ci:gate` 执行） | Maven 编译、Java 4/4 测试、jar 打包通过 |
| `verify:runner`（由 `ci:gate` 执行） | build/version 契约及安全字段边界校验通过 |
| `verify:e2e`（由 `ci:gate` 执行） | 生命周期契约通过；Chrome 4/4 通过，覆盖三页刷新、搜索、需求反馈、文案编辑、状态恢复与 390px/320px 布局 |
| `pnpm ci:gate` | 退出 0；输出 `[ci-gate] all stages passed` |
| 设置 `CODELESS_FORCE_FAIL=verify:runner` 后 `pnpm ci:gate` | pnpm 12.6.0 返回 86；其他真实阶段仍执行，最终输出 `[ci-gate] failed with exit code 86` |

复现前先按 README 准备 Corepack shim，并设置 Java 21 的 `JAVA_HOME`。Windows 使用本机 Chrome 时设置 `$env:CODELESS_PLAYWRIGHT_CHANNEL='chrome'`；CI 同样使用 Chrome 通道。

首轮 CI 的根冻结安装、静态、API 和 runner 检查已通过；浏览器安装器在 Chromium 下载 100% 后停滞超过 7 分钟，该轮已停止以取回日志。现改用 CI 镜像自带的 Chrome，保留原有浏览器用例，并为 E2E job 设置 10 分钟超时。
