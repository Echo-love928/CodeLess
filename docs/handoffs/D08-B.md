## PR 摘要、契约差异与限制

解决 D07 成功构建后缺少受限产物访问和浏览器真实裁定的问题。新增不可变产物快照、隔离服务/浏览器、受控动作、可分类失败、三类摘要/截图报告、源码快照到构建验证入口，并在原门禁中真实执行测试。

内部结果不等于公开 Build。Build 仅描述构建；ApplicationVersion 未定义 browser report/evidence 字段。公共维护者/最后启用 PR 须存储验证 ID、证据与摘要，确认对应版本/source/artifact一致，并消费真实 build+browser结果后推进 VERIFIED/READY。D07 真实退出0但构建失败的公共契约差异仍未改。本卡未添加公共接口、数据库迁移、认证发布或任务状态接线。

Browser 网络代理/routing/CSP 针对生成网页行为；部署仍需独立 worker 身份/容器、资源配额和外部 orphan 回收。浏览器漏洞隔离不是路由白名单所能替代的。此卡不安装新 browser 镜像、不挂平台密钥/socket。可见性基线支持实际文字/图片与动作断言；canvas/像素语义、250ms观察窗之后的任意未来行为不由本卡证明。截图固定 viewport；阶段超时可能没有截图，结果保持失败/未知。

静态服务为 worker 内部短期 capability 服务，非公开预览/发布接口。后续预览网关和源码/产物留存策略由对应维护者实施，失败不能覆盖最近可用版本。具体接口及示例见 services/runner/src/verify/README.md。
