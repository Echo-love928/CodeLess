## 与 D03-A 接口对齐

当前 `contracts/openapi.v0.json` 使用 Bearer security scheme，与 D03-A 的 HttpOnly 主机级会话 Cookie 相冲突。D03-A 在 `contracts/auth/README.md` 定义了以下候选契约；本分支已据此修改 `apps/web/src/api/auth.ts`：

| 请求 | 预期结果 |
| --- | --- |
| `GET /api/v0/auth/csrf` | 200 `{ token }`，建立主机级 HttpOnly 会话 Cookie |
| `POST /api/v0/auth/login`，JSON `{ email, password }`，`X-CSRF-Token` | 200 `{ id, email, displayName, role }` 并轮换会话 ID；错误为 401/403/429 |
| `GET /api/v0/auth/me` | 200 用户对象或 401，用于刷新恢复 |
| `POST /api/v0/auth/logout`，`X-CSRF-Token` | 204，服务端销毁会话；错误为 401/403 |

浏览器只以同源凭据模式发送 Cookie；不在前端持久化密码、会话 Cookie 或 CSRF token。前端的 CSRF token 仅保留在当前内存。公共 OpenAPI 的 Bearer/Cookie 差异仍需由契约维护者解决。
