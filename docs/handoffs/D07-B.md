## PR 摘要与限制

此前D05入口没有结构化日志/摘要和显式容器超时回收。本候选增加固定镜像上的独立任务执行、隔离限制、真值结果与失败清理，保留D05入口供原模块使用；现有门禁真实执行D07测试。原始日志和绝对路径仅供可信worker内部诊断，不能直接进入公开SSE/详情或成为模型指令。

成功必须同时满足退出0、有效受限产物与已确认清理。当前公共Build schema要求FAILED退出>=1，无法表达“工具退出0但产物无效/清理失败”；内部结果保留实际退出0和失败原因，不伪造非零码，也不强行映射SUCCEEDED。API接线PR需与公共契约维护者处理这一差异；本卡未修改公共契约。

执行器采用可信宿主Docker控制面，不能塞进D02无socket的健康容器后添加socket。artifactRoot应由可信worker/产物仓库维护；后续发布需核验摘要和已鉴权不可变版本。输出bind mount只有事后产物上限，非文件系统quota；部署需有容量受控的worker存储。宿主进程被外部强杀或Docker失联时，仅能如实报告/留下待清理状态，需要部署清理器接手。其他接线/运维要求见 `infra/runner/README.md`。
