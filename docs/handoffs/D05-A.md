## PR 摘要与限制

这项变更使任务创建、幂等、取消、事件和状态有持久化 HTTP 路径，并使多个 API 消费者依赖数据库锁和唯一索引协调。失败/未知结果不被当成成功。测试覆盖并发、取消、恢复、输入/权限和事务回滚。

D05-B 模板与离线镜像已有草稿 PR 候选，尚未与本任务队列真实联调。`TaskStageRunner` 是对接点；默认 adapter 明确失败为 `RUNNER_UNAVAILABLE`，不模拟生成成功。共享 `contracts/openapi.v0.json` 属公共契约维护者，本分支只在 `contracts/tasks/README.md` 提交增量差异；最终启用 PR 必须同步公共契约并用真实固定源码 fixture 做联调。Flyway V3 编号须与数据库迁移维护者协调，避免同日编号冲突。
