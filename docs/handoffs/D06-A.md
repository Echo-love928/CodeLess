## PR 摘要 / 契约 / 剩余限制

任务进度原来只能一次性读取历史；断线后没有可持续的鉴权订阅或明确续接游标。
此变更用数据库事件作为真值，新增 SSE 运输、严格升序续接、脱敏及有界补读；失败和未知
结果仍由状态查询明确呈现。验证涵盖真实 TCP 断线、取消、重连和数据库记录。

没有数据迁移/新依赖；可回退本提交恢复旧 JSON handler，持久化事件不删除。
可配置 poll-ms/heartbeat-ms 默认 500/15000，最小 10ms。
慢客户端可能占用 4 个发送线程之一直到 socket 结束；部署还须设代理 write/socket 超时，
64 连接是受控试用上限，尚未做压测，不宣称大型生产能力。

最终 SSE delta 见 `contracts/events/README.md`：同一路径 Accept 协商、task-event 命名帧、
sequence 为运输 id（资源 id 仍 UUID）、注释心跳、Last-Event-ID/header 优先、
JSON 分页、无 id 的 stream-error、终态查询后关闭 EventSource、按 sequence 去重。
共享 `contracts/openapi.v0.json` 和 schema 不在本卡登记维护范围；维护者必须在最终启用
PR 中同步 transport/参数/错误并运行公共契约验证。未由 A 擅自修改共享文件。
