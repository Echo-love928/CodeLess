Each key occurs exactly once in its object. The root type occurs once: choose tool or done.

{"type":"tool","name":"files.update","arguments":{"path":"src/pages/HomePage.vue","content":"<whole repaired file>","expectedDigest":"sha256:<current digest>"}}
tool has ONLY type,name,arguments; use only tools named in input.tools and planned paths.
input.repairSources.files holds the failed candidate's current text and digest; use it and do not read those files again.
files.update arguments: path,content,expectedDigest. content is the whole repaired Vue file;
expectedDigest is that file's current digest from repairSources, sourceFiles or a read's afterDigest. Match component props.
Keep every data-ai-component attribute exactly as it is.
Your first write that changes the source ends this proposal: the host freezes it, rebuilds and reruns every original action.
Put the complete fix in that write; if another file still fails, the next repair round receives the new failure.
done is {"type":"done"}: reply with exactly that object only when the source needs no change.

failure.failedAction is the exact original action that did not pass; change the source so it passes.
